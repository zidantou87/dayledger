# 日计 · 安装与使用（v1.0.4）

## 1. 安装

APK 在 `dist/dayledger-1.0.4.apk`（正式包 11.5 MB，Android 8.0 以上）。

> 想先看看有数据的样子：装 `dayledger-1.0.4-debug.apk`，然后在电脑上执行
> `adb shell am start -n com.dayledger.app/.MainActivity --ez demo true`，
> 会写入两周示例数据（只有空库才会写，正常用不会触发）。

任选一种方式传到手机：

- **数据线**：手机连电脑 → 选"传输文件" → 把 APK 拖进手机"下载"文件夹 → 手机上点开安装
- **微信**：电脑微信 → 文件传输助手 → 发送 APK → 手机点开 → 右上角"用其他应用打开"→ 安装
- **网盘/QQ**：同理

第一次安装会提示"未知来源"。按提示允许一次即可（这是所有非应用商店 APK 的必经步骤，不是这个 App 的额外权限）。

**它不联网。** 系统设置里能看到它没有任何网络权限，数据只在这台手机的本地数据库里。

## 2. 第一次打开（2 分钟）

1. 进「我的」→ 月预算改成你的数（默认 3600，日预算自动 = 月÷30）
2. 顺手改：每日热量、蛋白质目标、体重、专注目标、睡眠目标
3. 回「今天」，点右下角「记一笔」试一条

## 3. 每天怎么用（3 分钟）

| 什么时候 | 做什么 | 花多久 |
|---|---|---|
| 花钱时 | 「记一笔」→ 输金额 → 点分类 → 保存 | 3 秒 |
| 开始做事 | 「记一笔」→ 记时间 → 选活动 → 现在开始计时 | 2 秒 |
| 换事做 | 首页"进行中"卡片 → 停止 → 再开下一个 | 4 秒 |
| 吃饭 | 「记一笔」→ 记饮食 → 选餐次 → 填不填热量都行 | 5 秒 |
| 晚上 | 首页"今天的复盘"→ 点心情/精力 → 拖睡眠时间 → 存 | 30 秒 |

**补记也可以。** 日历里点任意一天，就能给那天补记录（补记的时间默认落在中午 12 点，可以之后再调）。

## 4. 番茄钟与权限

第一次点「现在开始」计时，会弹一次**通知权限**：

- 允许 → 通知栏常驻一条"工作 · 计时中"，带计时秒表和一个「停止」按钮；锁屏、切后台都继续走
- 拒绝 → 计时照样能用，只是没有常驻通知（后台被杀时可能断）

计时有四种：自由计时、番茄 25 / 45 / 60。番茄到点会：

1. 自动结束这一段并记进今天
2. 推一条「工作 · 25 分钟完成」的通知
3. 一句"起来动一下，喝口水"，不弹全屏、不锁你

点首页的「进行中」卡片，会进入**全屏专注页**（大字计时、屏幕常亮），点「结束这一轮」就收工。

**只申请两个权限**：通知、前台服务。不要悬浮窗、不要"使用情况访问"、不要电池优化白名单——那些是国产计时 App 为了后台保活乱要的。

## 5. 运动怎么记

记时间和记运动是同一个入口，只是活动选**运动类**：跑步 / 力量 / 骑行 / 游泳 / 球类 / 瑜伽 / 走路。

严格规则（也就是分怎么算）：

- **单次不到 10 分钟不计**，零碎走动不算一次训练
- **不同形式有强度**：跑步、游泳 ×1.2，力量、球类 ×1.1，骑行 ×1.0，瑜伽 ×0.8，走路 ×0.7
- 有效分钟 = 时长 × 强度，30 分钟封顶；连续分看最长的一次是否满 20 分钟

举例：跑步 30 分钟 = 有效 36 分钟 → 时长分拉满 70 + 连续分 30 = **100 分**；
三次各 10 分钟 → 有效 36，但最长只有 12 分钟 → 70 + 18 = **88 分**；
只走 5 分钟 → **0 分**（严格规则下不计入）。

## 6. 分数怎么看

- 总分 100，只算五项：时间 33.3% / 运动 11.1% / 饮食 22.2% / 执行 22.2% / 状态 11.1%
- **财务只记录，不计入总分**：预算、分类、结构照常统计，日报那行写"不计分"
- 原始分会被"可信度"往 60 收敛；**可信度不到一半时不出分**，只提示继续记录
- 报告页点任意维度，能看到这一项为什么扣分
- 不想看分：我的 → 评分 → 关掉"显示分数"

## 7. 数据与备份（重要）

- 数据全部在本机。**卸载 App 或换手机 = 数据没了**。
- 备份：我的 → 数据 → 导出备份 → 选个位置（建议手机里的"日计备份"文件夹）
- 恢复：新手机装好后 → 我的 → 导入备份 → 选那个 JSON
- 想重来：我的 → 数据 → 清空所有记录（保留分类和设置，删完就回到一张白纸）
- 建议每周导出一次；JSON 可以留多份，文件名带日期

## 9. 出问题怎么告诉我

装不上、打开闪退、某个页面空白、数字不对，直接说这四件事：

1. 手机型号 + Android 版本（设置 → 关于手机）
2. 在哪一步出的问题
3. 屏幕上看到的原话（或截图）
4. 之前装过没有

有这些信息我基本能定位。APK 每改一版都能直接覆盖安装，数据不会丢（只要不卸载）。
